사업 실행 계획 — 제출용 요약

버전 v1.0 요약기준일 2026-07-15 세부 실행 계획은 WBS v1.0 본문(별첨)으로 제공

01사업 개요

대상 시스템의 업무 규칙은 데이터베이스 내 프로그램(오라클 패키지) 소스에만 존재하여, 조회·수정·영향 파악에 특정 인력 의존도가 높다. 본 사업은 대상 프로그램 148개의 업무 문서를 AI로 자동 생성·검증하여 검색 가능한 지식 시스템을 구축하고, 임직원이 질문하면 근거와 함께 답을 얻는 환경을 만든다.

범위payments 영역 오라클 패키지 148개 (29만 6천 라인) — 착수 후 운영 기준으로 최종 확정
기간착수 후 약 4개월 (준비 5주 + 구축 10주) — 구축 일정은 AWS 환경 개통일(E, 목표 8/20) 기산
방식검증을 마친 표준 절차(문서 생성 → 이중 검증 → 적재)를 148개에 반복 적용 — 신규 개발 최소화
환경모든 AI 처리는 고객사 AWS 클라우드 내부에서 수행 — 소스코드 외부 반출 없음

02단계별 계획

단계기간주요 작업산출물점검
1. 준비착수~5주 요구사항 확정 미팅 · 작업 표준 확정(작성 규칙·검증 기준·진행 대장·추출 절차) · 전 과정 사전 리허설 · 대상 148개 운영 기준 확정 확정 요구사항서 · 표준 문서 4종 · 리허설 실측 리포트M1·M2
2. 환경E ~ E+2주 AWS 환경 구성·보안 점검(체크리스트) · 표본 실측으로 품질 목표 수치 확정 가동 환경 · 품질 목표치M3
3. 구축E+2 ~ 8주 148개 업무 문서 생성·검증·적재 (진행 현황 주간 공유) · 업무 전문가 질의 사이클 운영 업무 문서 148건 적재 완료M4
4. 오픈E+8 ~ 10주 최종 품질 측정(사전 합의된 시험 질의 20건) · 질의 창구 연결 검증 · 오픈 판정 품질 리포트 · 서비스 오픈M5
일정 전제 — 2~4단계는 AWS 환경 개통일(E)부터 기산한다. 개통이 지연되면 이후 일정은 동일 간격으로 순연되며(1단계는 영향 없이 진행), 변경 시 계획서를 재발행한다.

03최종 산출물

업무 문서 148건대상 프로그램 전체의 업무 설명 문서 — 표준 양식, 검색 시스템에 적재된 상태로 인도
AI 검색·질의 시스템고객사 환경 내 가동 — 자연어 질문에 근거를 첨부해 답변
질의 창구웹 채팅 기본 — 승인 시 개발자 도구 연동 추가
운영 문서 4종진행 대장 · 소스 추출 절차서 · 문서 작성 지침 · 품질 검증 기준서 (운영 인수인계용)
실측·품질 리포트리허설·표본·최종 품질의 측정 기록 — 목표 수치의 근거
(2단계) 자동화코드 변경 시 자동 문서 갱신 + 관리 화면 — 오픈 후 별도 협의

04기대효과

  • 업무 지식의 자산화 — 소스 코드에만 있던 업무 규칙이 검색 가능한 회사 문서로 축적
  • 확인·분석 시간 단축 — 코드 조회, 수정 영향 파악, 업무 규칙 확인을 질문 즉시 근거와 함께 제공
  • 신규 인력 적응 기간 단축 — 시스템 구조와 업무 규칙을 문서·질의로 자가 학습
  • 특정 인력 의존도 감소 — 담당자 부재·교체 시에도 업무 연속성 유지

06품질·검수 기준

C1 완료율148개 중 검증 통과·적재 완료 비율 — 목표치는 표본 실측(M3) 후 확정
C2 품질사전 합의된 시험 질의 20건의 정답률 — 목표치는 표본 실측(M3) 후 확정
C3 신뢰근거 없는 답변·추정 답변 0건 (지금 확정)
C4 투명성미확인 항목 현황 리포트 상시 제공 (지금 확정)
수치 확정 방식 — 목표 수치는 근거 없이 지금 적지 않고, 실제 환경 표본 실측(2단계) 후 그 결과를 근거로 확정하여 계획서를 개정한다. 측정 방법은 상기와 같이 지금 확정한다.

07주요 위험과 대응

환경 개통 지연구축 일정 동일 간격 순연 (준비 단계는 영향 없음) — 주간 확인으로 조기 관리
DB 접근 제한사본(스냅샷) 방식으로 전환 진행 — 접근 수준에 따라 검증 범위와 목표치를 연동 확정
AI 품질 미달표본 실측(M3)에서 조기 판정 — 작성 규칙 보강 또는 모델 교체 후 재측정
문서 체계 — 본 문서는 평가용 요약(3면)이다. 작업 25건의 세부 계획·판정 기준·위험 목록은 「사업 실행 계획서(WBS) v1.0」 본문으로, 배경·구성의 상세 설명은 「쉬운 설명판」으로 별첨 제공한다. 상충 시 WBS 본문이 우선한다.
