# 00. 사용자 환경 구성 매뉴얼 (로컬 Quickstart)

> 대상: 데모를 **자기 노트북에서 돌릴 사람**.
> 서버(MCP·DB·KB)는 이미 VPS에 배포돼 있다. **OpenCode 설치 + 전역설정 한 번이면 끝.**
> **데모 폴더는 받을 필요 없다** (그건 운영자/빌더용).
> 작성일: 2026-06-19

## 0. 3단계 요약

1. **OpenCode 설치** + 에이전트용 LLM 키
2. **전역 설정**에 MCP 2개(remote URL + 토큰) 붙여넣기
3. `opencode` 실행(아무 폴더에서나) → 질의

끝. 클론·폴더·node·터널 전부 불필요.

---

## 1. 전제

**이미 배포됨(건드릴 것 없음):** VPS의 MCP 2종 + 회수 DB(8테이블) + 규정 KB(13장).
**로컬에 필요한 것:** OpenCode + LLM 제공자 키(예: Anthropic) + 인터넷(HTTPS 443 아웃바운드).

---

## 2. 구성 단계

### 2-1. OpenCode 설치 + 모델 인증
- OpenCode 설치(공식: **opencode.ai**), 확인: `opencode --version`
- 에이전트가 판단에 쓸 **LLM 제공자 인증**(예: Anthropic 키)을 OpenCode에 등록(`opencode auth` 등).
  > 이게 없으면 도구는 붙어도 에이전트가 생각을 못 해 질의가 안 돈다.

### 2-2. 전역 설정에 MCP 2개 등록 ★ 핵심
OpenCode **전역 설정 파일**(홈 디렉토리의 OpenCode config, 예: `~/.config/opencode/opencode.json`)에 아래 `mcp` 블록을 넣는다. (이미 다른 설정이 있으면 `mcp` 키만 병합)

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "postgres": {
      "type": "remote",
      "url": "https://76-13-214-57.sslip.io/postgres/mcp",
      "headers": { "Authorization": "Bearer <MCP_TOKEN>" },
      "enabled": true
    },
    "lightrag": {
      "type": "remote",
      "url": "https://76-13-214-57.sslip.io/lightrag/mcp",
      "headers": { "Authorization": "Bearer <MCP_TOKEN>" },
      "enabled": true
    }
  }
}
```
→ 이제 **어느 폴더에서 `opencode`를 켜도** 두 도구가 따라온다.

### 2-3. (선택) 갭 탐지 연출 품질 높이기
기본 설정만으로도 도구는 붙고 데모는 된다. 다만 **"근거 블록 분리·갭 명시 지적"** 같은 연출 품질을 원하면, `AGENTS.md`의 지침을 OpenCode **전역 지침**으로 함께 적용한다(전역 설정 디렉토리에 `AGENTS.md` 배치). 지침 원문은 데모 폴더의 `AGENTS.md` 참고.

### 2-4. 실행 + 확인
```bash
opencode
```
OpenCode 안에서:
```
사용 가능한 MCP 툴 보여줘
```
→ `pg_query`, `pg_execute`, `lightrag_query` **3개** 보이면 구성 완료.

### 2-5. 데모 질의
```
이번 분기 중도해지 중 위약금 정책 위반 있어?
```
전체 시연(6막)은 → `docs/04_시연가이드.md`.

---

## 3. 자주 막히는 곳

| 증상 | 원인 / 조치 |
|------|-------------|
| MCP 툴 안 보임 | ① 전역설정 `mcp` 블록 위치·문법 ② 방화벽(HTTPS **443 아웃바운드**) |
| 에이전트가 답 못 함(툴은 보임) | OpenCode **모델 인증 누락**(2-1) |
| `401 unauthorized` | Bearer 토큰 오타/불일치 |
| 사내망 접속 실패 | 사내 프록시가 외부 HTTPS 차단 — 프록시 설정 또는 망 담당 협의 |

빠른 사전 점검(설정 전에 서버 생존 확인):
```bash
TOK="<MCP_TOKEN>"
curl -s -o /dev/null -w "%{http_code}\n" -X POST https://76-13-214-57.sslip.io/postgres/mcp \
  -H "Authorization: Bearer $TOK" -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'   # → 200
```

## 4. 보안·주의
- 전역설정에 **Bearer 토큰이 평문**으로 들어간다 → 설정 파일 공유·캡처 시 토큰 노출 주의.
- `pg_execute`는 **쓰기** 도구. 정정 시연(6막) 외에는 조회만 쓰는 게 안전(쓰기는 "고쳐줘"라고 명시할 때만 동작하도록 지침에 묶임).
