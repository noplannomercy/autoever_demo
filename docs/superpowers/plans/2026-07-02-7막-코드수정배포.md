**핵심 요구:**
- 파일 선두는 오라클 패키지 헤더를 모사한 변경이력 주석 블록(2008 최초작성~2024 패치 이력, 담당자 퇴사 흔적). 함수마다 한국어 레거시 주석·군데군데 주석처리된 옛 코드 블록(데드코드)을 남겨 현실감 부여. 전체 500~800라인 목표.
- 멱등: 선두 `CREATE SCHEMA IF NOT EXISTS pkg_collection;` + 전 함수 `CREATE OR REPLACE`.
- `f_calc_penalty` 본문(버그 버전)은 정확히 아래 로직 — 위약금 산정에 **고객 등급을 조회하지 않는다**:

```sql
CREATE OR REPLACE FUNCTION pkg_collection.f_calc_penalty(p_contract_id int)
RETURNS bigint AS $$
DECLARE
  v_principal bigint;
  v_status    text;
BEGIN
  SELECT lc.principal, lc.status INTO v_principal, v_status
    FROM loan_contract lc
   WHERE lc.contract_id = p_contract_id;
  IF NOT FOUND THEN
    RAISE EXCEPTION 'PKG_COLLECTION.F_CALC_PENALTY: 계약 없음 (%)', p_contract_id;
  END IF;
  IF v_status <> '중도해지' THEN
    RETURN 0;
  END IF;
  -- 위약금 = 잔여원금 x 2% (2019-03 요율 개정, 구 3%)
  -- ※ 등급별 예외는 영업지원팀 수기 정정으로 운영 중 (2021-06 김OO)
  RETURN round(v_principal * 0.02);
END;
$$ LANGUAGE plpgsql;
```

(`수기 정정으로 운영 중` 주석이 서사의 핵심 증거 — 역문서에도 그대로 인용된다.)

- 나머지 4개 함수는 규정 문서(회수규정_01/02/04/07)와 용어사전(_13)의 산식·코드값을 그대로 구현. 조회 전용 로직으로 작성하고, 쓰기가 있는 `sp_apply_deposit`/`sp_nsf_convert`는 INSERT 대상 존재 시 중복 방지 가드(`NOT EXISTS`)를 넣어 시연 중 오호출돼도 데이터가 깨지지 않게 한다.
