# Code2Rule POC 시연 프레젠테이션 (HTML 덱) — 설계

> 작성: 2026-07-11 · 상태: **구현 완료 (본편 동결)**
>
> 구현 중 확장(사용자 승인): 19장 → **22장** (무대전환 다크 슬라이드 · 갭 스코어보드 6/5/4 · 무대 뒤 장비목록),
> 전역 순차 등장 스태거 + ≠ 팝 + diff 줄단위 출력 + 타이핑/카운트 연출 (R=재생),
> **발표자 보기**(V 키: 청중 창 분리 + 대본 22장 내장 + 타이머, T=타이머 리셋),
> Q&A는 본편에 넣지 않고 `Code2Rule_POC_시연_FAQ.md`로 별도 대응.

## 목적·용도

- **겸용**: 라이브 시연(OpenCode+SQLTools) 동반 발표덱 + 배포 후 단독으로도 읽히는 자료
- **청중**: 혼합(임원+실무) — 임팩트 장면 우선, 실무 디테일은 보조 섹션
- **시연 백본**: `docs/07_시연시나리오_쉬운버전.md` (VIP 위약금 단일 아크, 6장면, 리허설 실측 완료)
- **내러티브**: 콜드 오픈 — 결과("2줄 고치려고 2주 → 몇 분")부터 던지고 풀어냄

## 산출물

- `docs/Code2Rule_POC_시연.html` — **의존성 0 단일 파일** (폐쇄망 브라우저에서 그대로 열림)
- 키보드(←→/Space) 넘김, 하단 진행 바, 인쇄(PDF 저장) CSS 포함
- 외부 리소스 금지: 웹폰트 CDN·외부 이미지 없음. 다이어그램은 인라인 SVG

## 메시지 시스템

- **숫자 히어로 5종**(반복 노출): `2줄/2주` · `4건` · `₩3,440,000` · `1,460,000→0` · `몇 분`
- **반복 기호**: `규정 ≠ 데이터`(갭 마크, 레드), `탐지→정정→검증`(루프 마크, 그린)
- 슬라이드당 선언문 1개 + 증명 비주얼 1개. 불릿 나열 금지(최대 3개)
- 발표자 노트: 각 슬라이드 하단 주석(HTML comment 또는 `?notes` 토글)으로 07 문서의 멘트 수록

## 비주얼 시스템

- **팔레트**: 배경 `#FAF9F6` · 네이비 `#0F2440` · 골드 `#C9A227` · 레드 `#C43D2F` · 그린 `#1E7A46` · 다크패널 `#0D1B2A`
- **타이포**: `Pretendard, 'Noto Sans KR', 'Malgun Gothic'` / 코드 `'D2Coding', 'Cascadia Code', Consolas`. 훅은 7–10vw 초대형, 자간 타이트
- **다크 스크린 패널**: 타이틀바(신호등+타이틀) + 본문. 채팅형(에이전트), SQL형(신택스 컬러), diff형(+그린/−레드 행 하이라이트)
- **사람 검증 배지**: 골드 원형 배지 + "사람 검증 ①②③" — 에이전트 장면과 명확히 구분
- **레이아웃 그리드**: 좌측 골드 세로 룰 + 파트 라벨(훅/문제/무대/시연/원리/적용), 우하단 페이지 번호
- 애니메이션은 절제: 슬라이드 전환 fade, 숫자 카운트업(장면1·6)만. 폐쇄망 저사양 대비 CSS 전용

## 데이터 정합성 (모두 저장소 실측값)

- 갭: 4건 (contract 63/133/203/273), 합 ₩3,440,000 (개별 1,460,000/1,060,000/660,000/260,000)
- 검증 쿼리: `f_calc_penalty(63)` 1,460,000→0 / `f_calc_penalty(7)` 340,000 불변
- VIP 중도해지 42건 중 38건 수기 0원 처리, 코드 주석 "2021-06 수기 정정"
- 무대: 고객 2,000 · 계약 3,000 · 상환스케줄 12,600 · 청구 2,500 · 입금 2,100 · 연체 229 · 규정 13장 · 함수 5개
