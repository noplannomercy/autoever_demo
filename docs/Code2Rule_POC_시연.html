①사람 검증

“정말이야?” — 담당자가 직접 확인합니다.

AI 말을 믿는 게 아니라,
검증하고 씁니다.

SQLTools — demo_legacy
SELECT b.contract_id, c.grade, b.amount
FROM billing b
JOIN loan_contract lc ON lc.contract_id = b.contract_id
JOIN customer c ON c.customer_id = lc.customer_id
WHERE b.bill_type = '중도해지위약금'
  AND c.grade = 'VIP' AND b.amount > 0;

장면 3 · 에이전트 — 원인 추적

원인은 5년 전
주석 한 줄에 있었습니다.

pkg_collection.sql — f_calc_penalty()
CREATE FUNCTION pkg_collection.f_calc_penalty(p_contract_id bigint) BEGIN SELECT lc.principal, lc.status ... -- 고객 등급은 조회하지 않음 RETURN v_principal * 0.02; -- 등급별 예외(면제)는 영업지원팀 수기 정정으로 운영 중 (2021-06) END;

에이전트가 스스로 찾아낸 것:

① 위약금은 f_calc_penalty가 계산하는데, 고객 등급을 아예 보지 않는다

② 면제는 코드가 아니라 사람의 수기 정정으로 운영 중 — 코드 주석이 증언

③ 결론: 데이터 정정만으론 다음 분기에 재발한다

데이터가 입증하는 결론

사람이 매번 고치는 프로세스는,
언젠가 빠뜨립니다.

장면 4 · 에이전트 — 수정안

고치는 건, 딱 2줄이었습니다.

diff — legacy_src/pkg_collection.sql
 DECLARE   v_principal bigint; + v_grade text;  BEGIN - SELECT lc.principal, lc.status + SELECT lc.principal, lc.status, c.grade   FROM loan_contract lc + JOIN customer c ON c.customer_id = lc.customer_id   WHERE lc.contract_id = p_contract_id; + IF v_grade = 'VIP' THEN RETURN 0; END IF; -- 회수규정_05

등급을 조회하고, VIP면 면제한다.
규정 조항(회수규정_05)이 주석으로 남습니다.

이 2줄을 확인하는 데
원래 2주가 걸렸습니다.

에이전트는 아직 배포하지 않았습니다.
승인을 기다립니다.

②사람 검증

통제는 사람에게 있습니다.

diff가 2줄이라 담당자가 눈으로 읽고 판단할 수 있습니다.
읽을 수 있는 변경만 승인할 수 있고,
승인 없이는 아무것도 배포되지 않습니다.

opencode — 승인 대기

diff를 제시했습니다. 승인 전에는 배포하지 않습니다.

승인. 배포하고 검증까지 해줘.

pg_execute → CREATE OR REPLACE FUNCTION f_calc_penalty ...

배포 완료. 자체 검증: VIP 42건 전부 0원,
일반 386건은 기존대로 원금의 2% — 의도한 변화만 발생.

수칙내용
계획 먼저모든 변경은 실행할 SQL과 대상 범위를 먼저 제시
전후 대조변경 전 조회(before) → 실행 → 재조회(after)를 건수와 함께 보고
범위 한정WHERE 없는 UPDATE/DELETE 금지 — 항상 식별자로 한정
권한 분리읽기(pg_query)와 쓰기(pg_execute)는 별개 도구 — 쓰기는 승인 전제
근거 의무답변마다 데이터 출처(테이블·행 ID)와 규정 출처(문서명) 첨부
실환경 적용

오늘 보신 건 4단계.
시작은 1단계부터.

1 · 문서 생성

코드·규정 분석으로 업무 문서 자동 생성. 현재 적용 가능한 1차 범위.

2 · 업무 챗봇

규정 질의 응답, 출처 기반 답변. 읽기만.

3 · Read-only 연계

실데이터 조회 결합. 권한·마스킹 적용.

4 · 실행형 Agent

승인 기반 정정·배포. 오늘 보신 장면 — 통제 관문 통과 후.

단계마다 넘어야 할 관문: 인프라(폐쇄망·VPC) · 보안(마스킹·접근권한) · 운영통제(승인·롤백) · 감사(이력·책임 추적)
