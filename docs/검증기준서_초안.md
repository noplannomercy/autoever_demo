# 역문서 검증 기준서 (초안 v0.1)

> WBS 1.13 산출물 · 2026-07-16 · 근거: SRS R-05(이중 자동 검증)·R-08·R-13, P6(추정 금지)
> 실체: 이미 구현·시연된 검증 2루프(LLM 채점 + 기대 그래프 diff)를 기준서로 승격
> **합격 임계값 등 수치는 드라이런(1.14) 실측으로 확정한다 — 방식은 지금, 수치는 실측 후.**

## 0. 구조 한눈에

```
역문서 1건
  → L1 기계 대조 (결정적 · 전수 · 자동)     통과 못 하면 즉시 재생성
  → L2 LLM 채점 (루브릭 · 전수 · 자동)      점수를 대장에 기록
  → L3 표본 사람 검증 (회차당 소수 · 캘리브레이션)
  → [조건부] 실행·데이터 대조 (1.5 접근 수준 판정에 따름)
  → 통과 → KB 적재 (R-06)
```

- 검증은 승인 게이트가 아니다(P5 무정지) — 미달은 사람 결재가 아니라 **자동 재생성 대상**이 된다(R-08: 재생성도 동일 절차).
- 모든 결과(통과 여부·점수·일시)는 관리 대장에 기록한다(R-05).

## 1. L1 — 기계 대조 (결정적 검사)

소스에서 기계적으로 추출 가능한 사실과 문서를 구조 대조한다. 환각이 개입할 수 없는 앵커.

| # | 검사 | 방법 | 판정 |
|---|------|------|------|
| L1-1 | 반입 무결성 | 파일 라인수 ↔ 대장 라인수 대조 (절단 감지 — 대장 규칙 승계) | 불일치 = 실패 |
| L1-2 | 함수 커버리지 | 스펙 선언 함수/프로시저 전수가 문서에 섹션으로 존재 (R-04② 함수별 섹션 전제) | 누락 = 실패 |
| L1-3 | 의존성 diff | 문서 의존성 섹션 ↔ 딕셔너리 스냅샷(ALL_DEPENDENCIES)의 **기대 그래프 대조** | 차집합 = 실패(사유 기록) |
| L1-4 | frontmatter 스키마 | OKF v0.1 필수 필드(type·title·description·resource·tags·timestamp) 존재·형식 | 위반 = 실패 |
| L1-5 | 인용 실존 | Citations의 파일 경로가 실제 존재 | 깨진 링크 = 실패 |

- L1 실패는 점수가 아니라 **즉시 재생성**. L2로 넘어가지 않는다.

## 2. L2 — LLM 채점 (저지 루브릭)

소스(스펙+바디)와 역문서를 함께 주고 항목별 채점. 각 항목 판정에 **근거 인용을 필수**로 요구한다(저지 환각 방어).

| # | 항목 | 묻는 것 | 배점 |
|---|------|---------|------|
| J-1 | 누락 | 바디의 업무 규칙·분기·예외 처리 중 문서에 없는 것이 있는가 | /30 |
| J-2 | 과잉·환각 | 소스에 근거 없는 서술이 있는가 (있으면 해당 문장 인용 요구) | /30 |
| J-3 | 지침 준수 | 산문 서술체·매직넘버 의미 규명·조건의 업무 언어 번역·주의 지점 (1.12 지침 기준) | /20 |
| J-4 | 태깅 적절성 | 판단 불가 항목이 추정 없이 `[SME 확인 필요]`로 태깅되었는가 (P6) — 근거 없는 단정이 최악 | /10 |
| J-5 | 이해 가능성 | 코드를 못 보는 업무 담당자가 개요만 읽고 업무를 이해할 수 있는가 | /10 |

- 합격 임계값: `[TBD — 드라이런 실측 후]` (초기 가안: 총점 기준 + J-2·J-4는 개별 하한)
- 미달 문서는 재생성 대상(R-07②와 동일 경로). 점수는 대장에 기록하고 하위 문서는 L3 표본에 우선 편입.

## 3. L3 — 표본 사람 검증 (캘리브레이션)

1인 수행 전제(A4)에서 전수 사람 검토는 불가능하다. 표본의 목적은 개별 문서 심사가 아니라 **L2 점수를 믿을 수 있게 만드는 것**.

- 표본 규칙: 회차당 **저지 점수 하위 2건 + 무작위 2건** `[건수 TBD — 드라이런 후 조정]`
- 사람 판정: 통과/미달 2값 + 한 줄 사유
- 캘리브레이션: 드라이런에서 사람 판정 ↔ L2 점수의 상관을 재서 합격 임계값을 정한다. 운영 중 상관이 무너지면(사람 미달인데 고점수) 루브릭 개정 → 지침 개선 트리거(R-07③)와 동일 경로.

## 4. 조건부 루프 — 실행·데이터 대조

- 활성화 조건: **1.5 사실 계층 판정** 결과 정합성 있는 DB 접근이 확보된 경우에만.
- 운영계 읽기 확보 시: 문서가 서술한 계산·분기를 실데이터 표본으로 대조 (R-05②의 원형).
- QA 라이브만 가능 시: 공통코드류 등 정합 확인된 마스터성 데이터에 한정.
- 불가 시: 본 루프는 범위 이연(운영기 재협의) — L1 의존성 diff가 정적 대체재.

## 5. 대장 기록 필드 (1.10 연동)

| 필드 | 값 |
|------|-----|
| 검증 일시 | ISO 8601 |
| L1 | 통과 / 실패(항목) |
| L2 점수 | 총점 + 항목별 |
| L3 | 표본 여부·사람 판정 |
| 판정 | 통과(적재 가능) / 재생성 대상 |
| 재생성 횟수 | n (동일 문서 반복 미달 = 지침 문제 신호) |

## 6. 미결 (드라이런에서 채움)

1. 합격 임계값 (총점·항목 하한) — L3 캘리브레이션
2. L3 표본 건수 — 처리 속도 실측과 트레이드오프
3. 저지 모델·프롬프트 고정본 — 채점 재현성 확보(모델 버전 기록)
4. 회차당 검증 소요 시간 — 2.3 일정 산정 입력
