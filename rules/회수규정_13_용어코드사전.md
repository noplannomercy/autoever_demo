# 회수 도메인 용어·코드 사전

데이터(Postgres)의 코드값을 해석하기 위한 사전이다. 질의 시 이 정의를 기준으로 데이터를 읽는다.

## 고객 (customer)
- **grade** — 고객 등급. `VIP`(우량, 중도해지 위약금 면제 대상) / `일반`.
- **dti** — 총부채원리금상환비율(%). 신용 심사·자동승인 판정에 사용.

## 상품 (product)
- **product_type** — `신용대출` / `담보대출` / `오토할부` / `리스`.
- **auto_approve_yn** — 자동승인 가능 여부. `Y` / `N`.
- **max_dti** — 자동승인 허용 DTI 상한(%).
- **delinquent_rate** — 연체이자율(%). 연체이자 산정(회수규정_07)에 사용.
- **prepay_fee_rate** — 중도상환수수료율(%). 회수규정_08에 사용.

## 계약 (loan_contract)
- **status** — 계약 상태. `정상`(상환 중) / `완납`(상환 완료) / `중도해지`(만기 전 해지) / `연체`(납기 경과 미납).
- **principal** — 원금(원), **interest_rate** — 약정 금리(%), **term_months** — 약정 개월.

## 월 청구 (billing)
- **bill_type** — 청구 유형. `정기`(월 정기 원리금) / `중도해지위약금`(회수규정_05).
- **status** — `미납` / `완납`. **bill_ym** — 청구 년월(YYYYMM).

## 입금 (deposit)
- **method** — 수납 방법. `자동이체`(CMS) / `가상계좌`.
- **nsf_yn** — 자동이체 출금 실패(잔액부족 등) 여부. `Y`(실패=NSF, 회수규정_04) / `N`(정상).
- **paid_date** — 입금일(미납 시 NULL).

## 입금 상세=충당 (deposit_detail)
- **alloc_type** — 충당 대상. `연체이자` / `이자` / `원금`(필요 시 `수수료`).
- **alloc_seq** — 충당 순서. 숫자가 작을수록 먼저 충당. 규정상 순서는 회수규정_02(연체이자→이자→원금→수수료).

## 연체 (delinquency)
- **stage** — 연체 단계. `1단계`(30일 미만) / `2단계`(30~60일) / `3단계`(60일 이상). 회수규정_03.
- **overdue_days** — 연체일수, **overdue_principal** — 연체 원금, **overdue_interest** — 연체이자.

## 월 상환 스케줄 (repayment_schedule)
- **status** — `완납` / `예정` / `연체`.
- **installment_no** — 회차, **principal_due**/**interest_due**/**total_due** — 회차별 원금/이자/총액.
